# Stage 00 — foundations

Learn the Linux process model, C object lifetimes, virtual memory, ELF sections, dynamic linking, x86-64 registers, stack frames, endianness, and the difference between an address, a value, and a byte sequence. Use the three foundation labs before touching a vulnerability.

Checkpoint: explain what `main` receives, where its first three integer arguments live, why a stack address changes between runs, and what evidence `readelf -h` gives you.
