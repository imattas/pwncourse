# Capstone rubric

| Category | 0 | 1 | 2 |
|---|---|---|---|
| Root cause | copied claim | bug identified | source and runtime proof |
| Primitive | absent | named | limitations measured |
| Chain | opaque payload | mostly explained | every dependency and constraint |
| Reliability | one lucky run | mostly repeatable | assertions and repeated proof |
| Defense | generic advice | plausible fix | fix tested against original primitive |
| Communication | incomplete | readable | reproducible standalone writeup |
